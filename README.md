# 🌐 Masad Rayan — Modern Portfolio Website

A fully responsive, animated, modern **Developer Portfolio Website** built with **Next.js 16**, **Tailwind CSS 4**, **Framer Motion**, and **GSAP**.  
Showcases my skills, projects, and journey as a Full Stack / MERN Stack Developer.

🚀 **Live Demo:** [https://masad-rayan-portfolio.vercel.app/](https://masad-rayan-portfolio.vercel.app/)

---

## ⭐ Features

- ⚡ **Next.js App Router**
- 🎨 **Modern UI with Tailwind CSS 4**
- ✨ **Smooth animations using Framer Motion & GSAP**
- 🎥 **3D & blur effects**
- 📱 **Fully responsive across all devices**
- 📧 **Contact form with EmailJS**
- 🧩 **Modular component-based architecture**
- 🌙 **Minimalist clean design**

---
